# 组件入库标准

往库里加自己的动效组件，照这个来。**每条规则都能被 `npm run validate` 自动检查**——标准如果不能执行，过两个月就没人记得了。

```bash
npm run validate                                    # 检查 custom/ 下全部
node scripts/validate-component.mjs custom/Backgrounds/MyFx   # 检查单个
```

---

## 先搞清楚放哪

```
components/    上游 react-bits 镜像 —— 生成物，只读
               ⚠️ 每次 npm run sync 会整目录替换，手工放的东西必然被删

custom/        你自己的组件 —— 手写，git 跟踪，sync 永远不碰
```

**别往 `components/` 里加东西。** 那个目录会被整体替换掉（这是故意的，为了让上游删掉的组件在本地也消失）。

## 目录结构

```
custom/
  <类目>/
    <组件名>/
      <组件名>.tsx      入口，必须和目录同名
      meta.json         元数据（推荐）
      *.glb *.png       同目录资源（可选）
```

类目只能是这四个：`Backgrounds` `Components` `Animations` `TextAnimations`。

```
custom/Backgrounds/BreathingGrid/
  BreathingGrid.tsx
  meta.json
```

## 规则

### R1 · 目录结构对得上

目录名 = 文件名 = 组件名，类目在允许列表里。

**为什么**：索引、CLI 取用、选型台加载全都按这个约定寻址，错一个字就找不到。

### R2 · 源码能被解析

合法的 TSX。

**为什么**：依赖清单、参数表、资源清单全靠 AST 推导，解析不了就什么元数据都没有。

### R3 · 组件名唯一

不能和库里已有的 140 个重名。

**为什么**：取用命令 `add.mjs <名字>` 按名字寻址，重名会取错。

### R4 · 有 default export

```tsx
export default function MyEffect(props: MyEffectProps) { ... }
```

**为什么**：选型台用 `React.lazy` 加载，只认 `.default`。库里唯一的反例 `GridScan` 只有具名导出，它让 React 19 的 lazy 抛 `Cannot convert object to primitive value`——报错信息跟真实原因毫无关系，查了很久。

### R5 · props 写 TS interface

```tsx
export interface MyEffectProps {
  /** 网格线间距（px） */
  cellSize?: number;
  /** 呼吸一个来回的时长（秒） */
  duration?: number;
}
```

**为什么**：选型台的参数面板是从这里生成的——类型决定用滑块还是开关还是取色器，成员上方的注释成为提示文字。没有 interface 就只能退化成"有这么几个 prop"，面板基本没法用。

滑块的取值范围也从这里推：`cellSize` 命中尺寸量纲、`duration` 命中时间量纲、`opacity` 命中 0-1。**给 prop 起个符合量纲的名字，面板质量会好很多。**

### R6 · 能无参渲染

所有 prop 都有默认值，或者在 `meta.json` 的 `previewDefaults` 里给。

**为什么**：选型台是直接 `<Comp />` 挂上去的。有必填 prop 又没给默认值 = 一片白，而且报错信息往往指向别处。库里 `Masonry` `LogoLoop` `ChromaGrid` 都栽在这上面（`items.map is not a function`）。

### R7 · 不引外部网络资源

源码里不能有 `http://` / `https://` 的资源地址。图片用内联 data URI，字体用系统字体族。

**为什么**：这个库的立身之本是离线可用。外链在你开发机上一切正常，打包给离线用户才炸，而且**改一个参数触发重新加载时会卡住组件**——上游有 9 个组件中招（picsum / unsplash / Google Fonts / jsdelivr 的 face-api 权重）。

### R8 · 同目录资源要真的在

`import model from './card.glb'` 引用的文件必须存在。

**为什么**：取用时这些资源会跟着组件走，少一个目标项目就 500。

### R9 · public 资源要真的在

写死的 `/assets/xxx.glb` 这类绝对路径，文件要在库的 `public/` 下。

**为什么**：取用时会拷进目标项目的 public/ 并按需重写路径。文件不在，组件拿到的是 index.html，报 `Unexpected token '<'`。

### R10 · 依赖在 package.json 里声明过

组件 import 的第三方包，本库要装过。

**为什么**：不然选型台预览它就直接白屏。取用到别人项目时倒是不影响（CLI 会提示装），但你自己先得能看到效果。

### R11 · meta.json 写全

```json
{
  "category": "Backgrounds",
  "description": "缓慢呼吸的网格背景，零依赖纯 canvas，适合仪表盘打底",
  "source": "自制",
  "license": "MIT",
  "previewDefaults": { "cellSize": 48, "duration": 6 },
  "usage": "import BreathingGrid from './BreathingGrid';\n\n<BreathingGrid cellSize={48} />",
  "semantic": {
    "summary": "细线方格铺满整屏，整张网格的亮度按正弦缓慢明暗呼吸，颜色与格距可调",
    "motion": "整体呼吸",
    "mood": ["极简", "安静", "科技"],
    "palette": ["暗色", "单色", "可定制"],
    "intensity": "subtle",
    "scenes": ["后台界面", "数据看板", "空状态", "加载中"],
    "keywords": ["网格", "格子", "呼吸", "明暗", "脉动", "极简背景", "打底", "衬底", "轻量背景", "零依赖"],
    "avoid": "线条网格会跟表格、图表的栅格打架，数据密集的区域慎用"
  }
}
```

| 字段 | 作用 |
|---|---|
| `description` | 一句话说明。选型台和 `--list` 用它 |
| `source` | 自制？改自某个开源项目？写清楚 |
| `license` | 非自制的必须写，避免日后说不清 |
| `previewDefaults` | 选型台的初始参数。默认值不好看就在这儿调 |
| `usage` | 取用后 AI 参考的用法示例 |
| `semantic` | **最重要**。语义检索卡片，决定别人能不能找到它 |

### 关于 `semantic`

组件名几乎没有语义（Silk / Prism / Ferrofluid 从名字什么都看不出来），
别的 AI 助手拿到「想要个暗色流动的背景」时，全靠这张卡片匹配。

上游那 139 个是 AI 逐个看巡检截图标注出来的；**自有组件你自己写**——
你比任何模型都清楚它长什么样。写进 `meta.json` 的手写版优先级高于机器标注。

| 字段 | 怎么写 |
|---|---|
| `summary` | 20~35 字，**具体到视觉特征**。「炫酷的背景动画」等于没写，要写成「紫色丝绸质感的流动渐变，波纹缓慢起伏」 |
| `motion` | 运动特征 2~6 字：缓慢流动 / 逐字浮现 / 粒子飘散 / 跟随光标 |
| `mood` | 气质 2~4 个：科技 未来 优雅 高级 安静 柔和 梦幻 活泼 俏皮 硬核 暗黑 神秘 复古 极简 华丽 温暖 冷冽 自然 |
| `palette` | 色调 1~3 个：暗色 亮色 彩色 单色 霓虹 黑白 渐变 紫色系 蓝色系 暖色系 冷色系 可定制 |
| `intensity` | `subtle`（能当底衬）/ `moderate`（有存在感）/ `bold`（会成为焦点）。**别都往 bold 写**，满屏粒子放进后台界面是灾难 |
| `scenes` | 适用场景 2~4 个：Hero区 落地页 登录页 启动页 空状态 加载中 产品介绍 数据看板 导航 按钮 卡片列表 图片展示 标题 正文 页脚 后台界面 |
| `keywords` | 中文检索词 6~12 个，**这个字段决定能不能被搜到**。想「用户会怎么描述这个需求」，把那些说法都收进来。做流体背景就写：流动 液体 流体 波纹 渐变 丝滑 动态背景 全屏背景 |
| `avoid` | 什么时候**不该**用它。这条最值钱 —— 写下你调试时踩到的坑，别人就不用再踩一遍 |

`avoid` 举几个真实例子，看看该写到什么颗粒度：

> **BlobCursor** · 组件不吃 children，叠上去用时外层容器没有 `pointer-events:none` 会挡住下层点击，表单和后台别用
> **MetaBalls** · 默认 `enableTransparency=false`，组件会自己刷一层不透明纯黑，浅色页面上整块盖死
> **LaserFlow** · `alpha:false` 把画布清成纯黑，会在版面上戳出一块黑矩形，叠不到已有背景图上；父级零高就整个不显示

写完跑 `npm run semantic` 合进索引，然后验一下能不能搜到：

```bash
node scripts/add.mjs --find "<你觉得用户会怎么描述它>"
```

搜不到就是 `keywords` 没写对，回去补。

### R12 · 单文件、别太大

超过 80KB 会警告。

**为什么**：这个库的形态前提就是单文件组件——取用 = 拷一个文件（加可选资源）。多文件互引的组件不适合这套分发方式。

## 还有几条查不出来但很重要的

工具检查不了，但踩过：

**清理要干净。** `useEffect` 的返回函数里，rAF 要 cancel、定时器要 clear、监听要 remove、WebGL context 要 dispose。
上游 `LetterGlitch` 只 cancel 了 rAF 没清 resize 定时器，卸载后残留的回调继续跑，**报错还算到了下一个挂载的组件头上**——查这个花了很久。

**别注入全局 `<style>`，非注入不可就带前缀。** 上游有 7 个组件往页面注 style，`DomeGallery` 里一条 `.stage { position: absolute }` 直接把选型台的 `.stage` 变成覆盖全屏——表现是整页点不动，看起来像卡死，实际是布局被撞坏了。

**别把 `ref` 当普通 prop 接。** 那是 React 19 才成立的写法，React 18 宿主上 ref 会被吃掉，`props.ref` 是 undefined，**不报错，就是不动**。用 `forwardRef`。

**参数变化要能响应。** 选型台会实时把新 props 传下去。只在挂载时读一次 props 的组件，用户拖滑块看不到变化（会等 350ms 的兜底重挂）。在 `useEffect` 的依赖数组里列上那些 prop。

## 加一个组件的完整流程

```bash
# 1. 建目录
mkdir -p custom/Backgrounds/MyEffect

# 2. 写组件（照着 custom/Backgrounds/BreathingGrid 抄结构）
#    custom/Backgrounds/MyEffect/MyEffect.tsx
#    custom/Backgrounds/MyEffect/meta.json

# 3. 校验
npm run validate

# 4. 合并进索引
npm run index:custom

# 5. 合并语义卡片（meta.json 里的 semantic 块）
npm run semantic
node scripts/add.mjs --find "<你觉得用户会怎么描述它>"    # 搜得到才算过

# 6. 看效果
npm run dev        # 选型台里应该能搜到它，参数面板自动生成

# 7. 试着取用
node scripts/add.mjs MyEffect --to /tmp/test-host/src --dry-run
```

`BreathingGrid` 是照标准写的示例，可以直接抄它的骨架。

## 从别的地方搬组件进来

比如看到一个不错的 CodePen 或开源组件：

1. 确认许可证允许（MIT / Apache / CC0 都行，GPL 要小心）
2. 改造成单文件 + TS interface + 全默认值
3. 把外链资源换成内联或本地
4. `meta.json` 里 `source` 写原始出处，`license` 写原始许可证
5. 源码文件头保留原作者的版权声明
6. `npm run validate` 过了再合并

**别把来源不明的代码放进来。** 这个库是公开分发的，许可证说不清会很麻烦。
